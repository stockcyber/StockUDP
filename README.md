# StockUDP

Projeto em Python para estudos de UDP e sockets.

**Código aberto. Modifique à vontade — cada um assume as consequências do próprio uso.**

Use por sua conta e risco.

## Dependências

* Python 3
* Colorama

Instale a dependência:

```bash
pip install colorama
```

## Instalação

Clone o repositório:

```bash
git clone https://github.com/rafaelkkj123rs/StockUDP.git
cd StockUDP
```

Execute:

```bash
python StockUDP.py
```
